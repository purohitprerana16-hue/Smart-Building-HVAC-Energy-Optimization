# Smart Building HVAC Energy Optimization & Predictive Analytics

An end-to-end data analytics and predictive modeling project designed to optimize commercial building HVAC energy consumption and quantify carbon reduction metrics—mirroring smart infrastructure architectures like Danfoss Leanheat.

## 📊 Project Architecture
- **Data Engineering:** Extracting, cleaning, and structuring multi-variable environmental and thermal load datasets using SQL and Python.
- **Predictive Modeling:** Developing a Python machine learning model (Random Forest Regressor) to forecast building energy demands based on ambient temperature, humidity, and occupancy patterns.
- **Strategic Visualization:** Engineering a Power BI dashboard tracking automated energy efficiency gains, operational cost reductions, and Scope 2 carbon emissions mitigations.

## 💾 Data Source
Utilizing the open-source ASHRAE (American Society of Heating, Refrigerating and Air-Conditioning Engineers) Great Energy Predictor dataset framework.
